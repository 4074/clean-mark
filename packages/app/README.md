# @cleanmark/app

净印 Electron 客户端。应用内的水印清除逻辑来自 workspace 包 [`@cleanmark/lib`](../lib)。

## 运行

在仓库根目录执行：

```bash
npm install
npm run start:dev
```

## 打包

```bash
npm run package       # macOS
npm run package:win   # Windows x64
```

产物会写入仓库根目录的 `dist/`。使用说明、主题和算法说明见根目录 [`README.md`](../../README.md)。
